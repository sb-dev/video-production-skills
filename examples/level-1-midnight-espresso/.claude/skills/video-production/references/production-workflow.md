# Production Workflow

Use the shortest credible path that resolves the current production uncertainties.

## Canonical progression

```text
Brief
→ Visual Direction
→ Storyboard
→ Shot Plan
→ Optional Animatic
→ Reference Frames
→ Optional Motion Prototypes
→ Video Shots
→ Edit Timeline
→ Video Master
```

Optional stages remain optional. Escalate representation fidelity only when the cheaper representation cannot answer the current production question.

## Decision preservation

Prefer the most specific approved artifact available. A shot derived from an approved reference frame should not be recreated from the original brief unless the approved decision is intentionally reopened.

## Local correction

Classify failures before retrying. Fix the storyboard for sequence problems, the shot plan for shot-design problems, the reference frame for composition problems, the motion prototype/shot for motion problems, and the edit timeline for pacing problems.
