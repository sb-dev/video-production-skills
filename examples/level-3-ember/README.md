# Ember

**Level 3 — espresso machine**

A brushed-steel espresso machine with walnut controls in a dark kitchen, detail to extraction.

## Prompt

```text
Use video-production to create a 15-second premium commercial for a fictional espresso machine called "Ember".

Requirements:
- Duration: 15 seconds
- Format: 16:9 master plus 9:16 version
- Tone: tactile, warm, sophisticated
- Product: compact brushed-steel espresso machine with walnut controls
- Product geometry must remain stable
- Environment: dark contemporary kitchen
- Audio: grinder/mechanical details, espresso pour, steam, subtle music
- Graphics: simple "EMBER" final lock-up

Sequence should include:
- machine material detail
- preparation interaction
- espresso extraction
- steam or cup detail
- final product hero shot

Workflow:
- Establish product constraints and references
- Define warm commercial visual direction
- Storyboard the sequence
- Create shot-specific reference frames
- Generate candidates
- Select based on product fidelity, liquid realism, steam, and camera quality
- Assemble edit and audio mix
- Produce master and vertical delivery
- Run creative evaluation and technical QC

Optimise for:
- product fidelity
- believable mechanical interaction
- espresso and crema realism
- visible steam
- tactile sound design
```
