# Reference Frames

A reference frame is the approved visual target for one shot.

Build it from the most specific available approved inputs:

```text
visual direction
+ storyboard frame
+ shot plan
+ character/product/environment references
```

Use alternatives only when comparison is useful. Once selected, refine from the selected parent and preserve accepted identity, product, environment, composition, framing, lighting and styling.

Prefer reference-frame conditioning when it reduces the amount of composition and continuity the video model must invent at the same time as motion.
