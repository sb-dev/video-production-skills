# Room 417

**Level 4 — suspense micro-film**

A hotel guest notices small continuity clues that someone has been in the room.

## Prompt

```text
Use video-production to create a 30–40 second suspense micro-film called "Room 417".

Premise:
A hotel guest returns to their room and notices small details suggesting someone has been inside.

Nothing supernatural needs to appear. Suspense should come from continuity, framing, props, and editing.

Requirements:
- Duration: 30–40 seconds
- Format: 16:9
- Tone: quiet psychological suspense
- Main character: one hotel guest
- Shared environment: one consistent hotel room and corridor
- Persistent props:
  - suitcase
  - room key
  - glass of water
  - bedside object
- Dialogue: none
- Audio: hotel ambience, distant lift, room tone, subtle score

Sequences:

1. Return
Guest walks down corridor and enters Room 417.

2. Something Is Wrong
Small continuity clues are noticed: an object moved, curtain open, glass present, etc.

3. Realisation
The character recognises that someone has been there.

Workflow:
- Establish room geography before generating shots
- Lock character and prop references
- Storyboard exact continuity clues
- Shot-plan eyelines, inserts, object positions, and character movement
- Create reference frames
- Generate and select shots
- Assemble rough cut and verify that the audience can notice the clues
- Refine edit before regenerating media unnecessarily
- Finish sound and master
- Evaluate spatial continuity, prop continuity, tension, pacing, and technical integrity

Optimise for:
- precise prop continuity
- spatial coherence
- insert-shot readability
- restrained performance
- tension created through editing
```
