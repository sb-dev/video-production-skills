# Night Courier

**Level 4 — urban action micro-film**

A bicycle courier crosses the night city to find the destination is an abandoned building.

## Prompt

```text
Use video-production to create a 35–45 second urban action micro-film called "Night Courier".

Premise:
A bicycle courier receives a late-night delivery, crosses the city at speed, and discovers that the destination is an otherwise abandoned building.

Requirements:
- Duration: 35–45 seconds
- Format: 16:9
- Tone: nocturnal, kinetic, grounded
- Main character: one bicycle courier
- Persistent assets:
  - courier wardrobe
  - bicycle
  - delivery package
- Environments:
  - small late-night dispatch point
  - city streets
  - final abandoned building
- Audio: city ambience, bicycle mechanics, traffic, restrained rhythmic music
- Dialogue: optional, minimal

Sequences:

1. Pickup
Courier receives and secures the package.

2. Crossing the City
Multiple shots of travel, movement, intersections, and changing urban environments.

3. Delivery
Courier arrives at the unexpected destination and hesitates before entering.

Workflow:
- Create shared character, bicycle, and package references
- Establish a consistent night-city visual direction
- Storyboard all sequences
- Use animatic/previsualisation to resolve action geography and timing
- Plan individual shots and screen direction
- Generate selected reference frames
- Generate motion, using prototypes for difficult riding/action shots when necessary
- Build rough cut
- Diagnose continuity and pacing issues at the edit level
- Refine only affected shots or edit decisions
- Finish audio and master

Optimise for:
- character and bicycle continuity
- believable movement
- screen direction
- changing but coherent locations
- energetic editorial rhythm
```
