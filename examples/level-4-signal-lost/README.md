# Signal Lost

**Level 4 — sci-fi micro-film**

A lone technician detects a repeating signal; the station's exterior lights respond.

## Prompt

```text
Use video-production to create a 35–45 second science-fiction micro-film called "Signal Lost".

Premise:
A technician working alone at a remote communications station detects a signal that should not exist. The transmission begins repeating a short pattern. In the final sequence, the station's exterior lights respond to it.

Requirements:
- Duration: 35–45 seconds
- Format: 16:9
- Tone: restrained science fiction, atmospheric rather than action-heavy
- Main character: one technician
- Shared environments:
  - communications control room
  - narrow station corridor
  - exterior of the remote station
- Persistent props:
  - headset
  - communications console
  - signal display
- Dialogue: minimal or none
- Audio: electronic ambience, radio interference, environmental sound, restrained score

Organise the film into approximately three sequences:

Sequence 1 — Discovery
The technician notices an anomalous repeating signal.

Sequence 2 — Investigation
The signal intensifies while the technician moves through the station checking equipment.

Sequence 3 — Response
Exterior lights or systems begin responding to the pattern.

Workflow:
- Establish shared visual direction
- Create persistent character, environment, and prop references
- Storyboard each sequence
- Create an animatic where useful to resolve timing before expensive generation
- Create sequence-level shot plans
- Approve reference frames
- Generate and select shots locally
- Build a rough cut first
- Evaluate structure and pacing before polishing
- Create a fine cut
- Add audio, finishing, and master
- Run creative evaluation and technical QC

Preserve approved character, station, console, costume, and lighting decisions across all sequences.

Optimise for:
- coherent world building through visuals
- escalating tension
- cross-sequence continuity
- deliberate editorial pacing
- atmosphere and sound
```
