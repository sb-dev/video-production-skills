# Editorial

The authoritative editorial artifact is the edit timeline, not a review render.

Core progression:

```text
Selected Shots
→ Assembly
→ Rough Cut
→ Fine Cut
→ Picture Lock
```

The initial timeline only needs source selection, order, in/out, duration, basic transitions, and simple audio/title placement where required.

Picture lock is `decisionState: locked`. Reopening it is explicit.

Do not turn the project into a general nonlinear editing application.
