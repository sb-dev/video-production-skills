# Apex

**Level 3 — running shoe**

One shoe design survives product close-ups and dawn city running action.

## Prompt

```text
Use video-production to create a 15-second performance-running-shoe commercial for a fictional shoe called "Apex".

The same shoe design must survive both product close-ups and athletic action.

Requirements:
- Duration: 15 seconds
- Format: 16:9 master plus 9:16 social variant
- Tone: energetic, premium, performance-focused
- Product: white and graphite running shoe with a distinctive red heel element
- Location: modern city at dawn
- Character: one runner
- Audio: footsteps, breath, environmental sound, rhythmic music
- Graphics: minimal "APEX" end card

Sequence should include:
- macro shoe detail
- runner preparing
- dynamic running action
- hero product or finishing shot

Workflow:
- Define a product manifest and runner reference
- Storyboard the commercial
- Plan continuity between static product shots and worn-product action
- Create product-critical reference frames
- Use motion prototypes where action uncertainty is high
- Generate and select shots
- Edit for energy without losing product visibility
- Add program audio
- Produce master and vertical delivery version
- Evaluate shoe fidelity during motion, anatomy, physical interaction, pacing, and technical quality

Optimise for:
- product consistency under movement
- believable running mechanics
- impact and speed
- clear product visibility
- energetic editorial rhythm
```
