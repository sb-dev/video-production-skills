# Code of Conduct

We want this project to be a professional, constructive place to collaborate.

Contributors must communicate respectfully, critique ideas and implementations rather than people, avoid harassment or discriminatory conduct, and respect privacy and attribution.

Project maintainers may edit, reject, hide, or remove contributions or participation that materially undermine those standards. Serious conduct concerns should be reported privately using the contact route documented by the repository owner rather than opened as a public issue.
