# Authoring Workflow

Use this sequence when creating or materially revising a Video Production extension pack.

```text
inspect catalogue
→ decide reuse / adapt / create
→ define pack
→ derive production profile
→ define evaluation profile
→ define optional voice profile
→ create self-contained skill package
→ create behavioural evals
→ create canonical showcase
→ validate
→ register catalogue + benchmark coverage
```

## Reuse / adapt / create

### Reuse
Use an existing pack unchanged when it already expresses the required production grammar.

### Adapt
Use an existing pack plus project-specific instructions when the difference is local to one production.

### Create
Create a new pack only when the difference is stable, reusable and materially changes Video Production behaviour.

## Validation order

Do not catalogue first and validate later.

```text
package
→ evals
→ showcase
→ structural validation
→ behavioural acceptance
→ catalogue registration
```

If a required gate cannot be proved, report `BLOCKED`.
